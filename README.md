## 🀄 プロジェクト1: 麻雀牌譜分析・仮想メンバーシミュレータ (Mahjong Paipu Analytics & Simulator)

天鳳・雀魂の牌譜データをインポート・解析し、メンバー独自のエージェント構築や高速モンテカルロ対局シミュレーション（1,000局〜収支・実力推移グラフ）を行う分析プラットフォームです。

### 主な機能
1. **牌譜インポート & 解析 (`/importer`)**
   - 天鳳（URL, XML, JSON）および雀魂（URL, JSON, Paipu Log）のインポート
   - 和了率・放銃率・立直率・副露率・平均打点・放銃時の局・巡目・危険牌分析
2. **多角的分析ダッシュボード (`/analytics`)**
   - メンバーごとの成績比較、レーダーチャート、打牌傾向
3. **カスタム分析エージェント作成 (`/agents`)**
   - メンバー固有の思考アルゴリズムやペルソナ抽出
   - 何切るベンチマーク比較
4. **牌譜リプレイ再生ビューア (`/replay`)**
   - 巡目ごとの打牌・鳴き・リーチの完全再現
5. **仮想メンバー対局シミュレータ (`/simulator`)**
   - ⚡ **1,000局超高速モンテカルロ工場**: 仮想メンバー4名による大量対局で収支曲線・平均順位・レーティング推移を線グラフ化
   - 👁️ **リアルタイム卓**: 1局ごとの打牌とAI思考ログを観戦

### 実行方法
```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev
# -> http://localhost:3000
```
