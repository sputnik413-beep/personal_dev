## 📈 プロジェクト1: 5分足・1分足スキャルピングAIエージェント & フォワードテストプラットフォーム

5分足および1分足を対象とした、短期デイトレード・スキャルピングに特化したAI自動売買エージェント＆フォワードテスト実行基盤です。
将来的な個人口座での自動売買接続を見据え、リアルチャートデータに基づき**スプレッドゼロ（Spread 0.0 pips）口座想定**での収支と統計的信頼性をフォワードテストで検証します。

### 💡 トレード思想と設計方針
1. **短期足スキャルピング（薄利の高速積み重ね）**
   - **対象通貨ペア**: USD/JPY (ドル円) または EUR/USD (ユーロドル)
   - **時間足**: 5分足（王道・推奨）および 1分足（高頻度・多試行）
   - **スプレッド**: 0.0 pips（ゼロスプレッド口座想定により、2〜4 pipsの微細な押し目反発でも即座にプラス圏浮上）
   - **利確 (TP)**: 4.0 〜 8.0 pips
   - **損切 (SL)**: 3.0 〜 5.0 pips
   - **トレーリングストップ**: +2.0 pips到達で自動追従開始、利益を確実にロック

2. **マルチ指標判定（Bob Volman式プライスアクション + クオンツ指標）**
   - **21 EMA（ロールリバーサル）**: 押し目・戻り目のアンカーライン
   - **50 EMA / 200 EMA**: 大局トレンドフィルター（パーフェクトオーダー判定）
   - **ボリンジャーバンド (20, 2σ)**: スクイーズ収束からのエクスパンション・ブレイクアウト
   - **RSI (14)**: 30以下（売られすぎ急反発）/ 70以上（買われすぎ急反落）の逆張りスキャルプ
   - **ATR (14)**: ボラティリティ適正評価

3. **Gemini 2.5 Flash AIクオンツ診断**
   - リアルタイムチャート・マルチ指標を深層解析し、確信度スコア（0〜100）と定性的な相場アドバイスを出力

### 🌐 【重要】PCを閉じていても2週間動かし続けるための運用アーキテクチャ

#### 1. プラットフォーム特性と制約の整理
- **AI Studio Webプレビュー（無料枠）**:
  ブラウザタブを閉じた後、リソース節約のため**約10〜15分でコンテナがスリープ（一時停止）**します。
  そのため、Web画面単体のみではPC停止時の2週間常時連続稼働は完結しません。

#### 2. 解決策A: GitHub Actions 自動フォワードテスト（費用0円・完全無料・推奨）
本リポジトリに `.github/workflows/scalping_forward_test.yml` を同梱しています。
- **仕組み**: 為替市場の開場平日（月曜〜金曜）、GitHubのクラウド実行環境が**5分おきに自動起動**。
- **処理**: Yahoo Finance等のリアル為替レートを取得し、スキャルピング戦略を実行。
- **永続化**: 約定結果や資産残高を `scalping_state.json` に記録してリポジトリに自動コミット・プッシュ。
- **結果**: **PCを完全にシャットダウンした状態でも、2週間〜1ヶ月間完全に放置でフォワードテストが継続されます。**

#### 3. 解決策B: さくらVPS / さくらクラウド常時稼働デーモン
本プロジェクト同梱のスタンドアロンデーモン `scripts/scalper-daemon.ts` をVPS上で起動します。
```bash
# 1. リポジトリをクローン
git clone https://github.com/sputnik413-beep/personal_dev.git
cd personal_dev

# 2. 依存関係インストール
npm install

# 3. PM2でデーモンを24時間常駐稼働
npm install -g pm2
pm2 start "npm run daemon" --name "fx-scalper"
pm2 save

# ログ確認
pm2 logs fx-scalper
```
